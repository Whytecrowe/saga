Build for Android:
saga-slint-ui
cargo apk build --target aarch64-linux-android --lib

Start Emulator:
/home/whytecrowe/Android/Sdk/emulator/emulator -avd Saga_Test &
!!!
Start emulator in background with proper flags
/home/whytecrowe/Android/Sdk/emulator/emulator -avd Saga_Test -no-snapshot-load > /dev/null 2>&1 &

Run on Emulator/Device:
Start Android emulator first (from Android Studio)
OR connect physical device via USB
cargo apk run --target aarch64-linux-android --lib


Debug on Device:
View logs
adb logcat | grep -i slint

Or all Rust logs
adb logcat | grep -i rust
