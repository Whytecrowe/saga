# Saga

> *The echo of your path.*

A privacy-first, offline journaling app for Android built with Rust.

## Features

- 📝 **Markdown journaling** - Rich text with full Markdown support
- 🗂️ **Organized by sections** - Meditation, Work, Fitness, or custom categories
- 📅 **Day-centric view** - Your daily Echoes at a glance
- 🔒 **Offline-first** - Your data stays on your device
- 🦀 **Built with Rust** - Fast, safe, and efficient

## Status

🚧 **In active development** - Not ready for production use

## Building
```bash
# Run tests
cargo test

# Build
cargo build --release

# Run (desktop only for now)
cargo run
```

## Tech Stack

- **Language:** Rust 🦀
- **Storage:** SQLite (via rusqlite)
- **UI:** Slint (cross-platform)
- **Target:** Android (Galaxy S23 Ultra), Desktop later
